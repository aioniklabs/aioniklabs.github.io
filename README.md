# aioniklabs.github.io

Dieses Repository ist für GitHub Pages konfiguriert.

## Deployment

Der Workflow [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml) veröffentlicht die Website automatisch bei Push auf `main` oder `master`.

Zusätzlich kann der Workflow manuell über **Actions -> Deploy GitHub Pages -> Run workflow** gestartet werden.

## GitHub-Einstellung

In den Repository-Einstellungen unter **Pages** muss als Source **GitHub Actions** ausgewählt sein.
